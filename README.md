# Qiyas AI Learning Labs

A collection of practical Python and AI learning exercises created during the Qiyas program. The repository documents foundational programming concepts through focused Jupyter notebooks.

## Topics covered

- Python function design
- List comprehensions
- Applied programming exercises
- Notebook-based experimentation

## Contents

- `qiyas-lab-day3.ipynb` — guided learning exercises
- `qiyas-lab-function-concepts.ipynb` — function fundamentals
- `qiyas-lab-list-comphresion.ipynb` — list-comprehension practice

## Getting started

```bash
python -m pip install jupyter
jupyter lab
```

Open the notebooks from the Jupyter interface and run the cells in order.
