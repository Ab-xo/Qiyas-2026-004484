# Qiyas — Data Science & AI Training Labs

This branch tracks hands-on lab work and assignments completed as part of
the **Qiyas Advanced Digital Skills for Young Graduates** training program
at Addis Ababa University (AAU), under the Data Science and Artificial
Intelligence track.

## About the Program

Qiyas is an AAU initiative that equips young graduates with practical,
in-demand tech skills across software development, data analytics,
artificial intelligence, Android development, and digital entrepreneurship,
combining mentorship with real, hands-on project work toward recognized
certification.

## About this Branch

This branch is used to submit lab exercises and homework assignments
completed during the course. Each notebook here corresponds to a specific
hands-on lab from the program.

## Labs in this Branch

| Notebook | Topic |
|---|---|
| `qiyas-lab-pandas-data-cleaning.ipynb` | Cleaning and analyzing a university student dataset with pandas (handling missing values, imputation, descriptive statistics) |

More labs will be added here as the course progresses.

## How to Run

Open any notebook in Jupyter and run the cells from top to bottom — later
cells generally build on the state created by earlier ones.

## Requirements

- Python 3
- pandas
- numpy
